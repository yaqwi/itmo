# Лабораторная работа №1

## Задание

Написать программу на языке Java, выполняющую указанные в варианте действия.

### Требования

- Программа должна корректно запускаться, выполняться и выводить результат без ошибок
- Математические выражения должны вычисляться с соблюдением порядка выполнения действий
- Необходимо использовать математические функции стандартной библиотеки Java
- Вычисление элемента двумерного массива должно быть реализовано в отдельном статическом методе
- Вывод матрицы должен быть реализован в отдельном статическом методе
- Результат должен выводиться в виде матрицы с четырьмя знаками после запятой
- Программа должна быть упакована в исполняемый JAR-архив
- Работу программы необходимо продемонстрировать на сервере Helios

Появление значения `NaN` при некоторых вычислениях допускается условиями задания.

## Вариант

Создать одномерный массив `e` типа `int` и заполнить его нечётными числами от 3 до 25 включительно в порядке возрастания.

Создать одномерный массив `x` типа `double` и заполнить его 15 случайными числами в диапазоне от −6.0 до 8.0.

Создать двумерный массив `f` размером `12 × 15`. Элементы массива вычислить по формулам, где `x = x[j]`.

### Если `e[i] = 19`

$$
f[i][j] =
\left(
\arctan\left(
0.2 \cdot \frac{x+1}{14}
\right)
\right)^{
\frac{0.25}
{\arcsin\left(e^{-|x|}\right)-1}
}
$$

### Если `e[i] ∈ {5, 9, 11, 13, 17, 23}`

$$
f[i][j] =
\cos\left(
\cos\left(\sqrt[3]{x}\right)
\right)
$$

### Для остальных значений `e[i]`

$$
f[i][j] =
\left(
0.25 -
\left(
\sqrt[3]{x^{x-\frac{3}{4}}}
\right)^{
3+\cos\left(\sqrt[3]{x}\right)
}
\right)^{
\arcsin\left(
e^{
\sqrt[3]{
-\left(\frac{4}{|x|}\right)^x
}
}
\right)
}
$$

Полученный массив вывести в виде матрицы с четырьмя знаками после запятой.
